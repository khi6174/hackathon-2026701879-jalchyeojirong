## 프로젝트 개요

배드민턴 동아리 임원이 활동 내역을 기록하고, **참여자를 회원 명부에서 선택**해 "누가 얼마나 참여했는지"를 추적하는 순수 HTML/CSS/JS 웹앱.

기존 문제: 활동 기록이 채팅방에 흩어져 있어 언제 모였는지, 누가 얼마나 나왔는지 파악 어려움.

**핵심 설계**: 참여 인원을 "숫자"가 아닌 "회원 연결"로 저장 → 회원별 참여 횟수가 자동으로 집계됨.

## 기술 스택

- **프론트엔드**: HTML / CSS / JavaScript (프레임워크 없음)
- **데이터 저장**: 브라우저 localStorage
- **외부 라이브러리**: 없음 (순수 vanilla JS)

## 구현 기능

### 필수 기능 ✓

- ✅ 회원 등록 (이름 + 실력 등급 상/중/하)

- ✅ 활동 목록 조회 (최신순 정렬, 참여자 이름 표시, 빈 목록 안내)
- ✅ 활동 삭제 (확인 절차 포함)

### 선택 기능 ✓

- ✅ 활동명·장소 키워드 검색
- ✅ 활동 수정 (인라인 편집)
- ✅ 통계 (총 활동 수 / 총 참여 연인원 / 평균 참여 인원)
- ✅ **회원별 참여 횟수 랭킹** (차별화 기능)
- ✅ 반응형 레이아웃 (모바일 대응)
- ✅ 샘플 데이터 로드 버튼 (시연용)

## 실행 방법

### 로컬 실행

1. **저장소 클론**
   ```bash
   git clone https://github.com/sung2ne/20260805.git
   cd hackathon
   ```

2. **`index.html` 브라우저에서 열기**
   - 파일 탐색기에서 `index.html` 더블클릭
   - 또는 브라우저 주소창에 `file:///C:/Users/USER25/claude/hackathon/index.html` 입력
   - 서버 필요 없음 (모든 데이터는 로컬 localStorage에 저장)

### 기본 사용 순서

1. **회원 등록** — "회원 명부" 섹션에서 이름 + 실력 등급 입력 → "회원 추가" 버튼
2. **활동 등록** — "활동 등록" 섹션에서 활동명·날짜·장소·참여자(체크박스)·메모 입력 → "활동 등록" 버튼
3. **활동 조회** — 우측 "활동 목록"에서 최신순으로 표시됨
4. **통계 확인** — 우측 "통계" 카드에서 총 활동 수/연인원/평균 확인
5. **참여 랭킹** — "회원별 참여 횟수" 카드에서 회원별 참여 횟수 확인

### 기능별 상세 사용법

- **검색**: 좌측 "검색" 섹션에서 활동명 또는 장소 입력 → 우측 목록이 실시간 필터됨
- **수정**: 활동 카드의 "✏️ 수정" 버튼 클릭 → 폼에 해당 활동이 로드됨 → 수정 후 "활동 등록" 제출
- **삭제**: 활동 카드의 "🗑️ 삭제" 버튼 클릭 → 확인 팝업 → 삭제 완료
- **매칭**: 회원 등록 후 우측 "매칭" 섹션의 "1vs1 매칭" 또는 "2vs2 매칭" 버튼 클릭
- **샘플 데이터**: 헤더의 "샘플 데이터 로드" 버튼 클릭 → 회원 6명 + 활동 5건 자동 주입

## 데이터 구조

### 회원 (localStorage 키: `members`)
```js
{
  id: "고유ID",
  name: "김영우",
  skillLevel: "상" | "중" | "하",
  createdAt: 타임스탬프
}
```

### 활동 (localStorage 키: `activities`)
```js
{
  id: "고유ID",
  title: "정기 랠리 모임",
  date: "2026-08-05",
  place: "서울 강남 배드민턴장",
  participantIds: ["회원ID1", "회원ID2", ...],
  memo: "복식 위주, 신입 1명 참여",
  createdAt: 타임스탐프
}
```

**핵심**: `participantIds`는 참여한 회원 ID 배열이므로, 참여 인원수는 `participantIds.length`로 계산.

## 범위 밖 (의도적 제외)

명세서 명시 사항 및 시간 제약에 따라 아래는 구현하지 않음:

- **기기 간 / 사용자 간 데이터 공유** — localStorage는 한 브라우저 안에서만 유지. 스마트폰과 노트북에서 서로 다른 데이터 생성. 실사용에는 서버·계정 필요.
- **회원 삭제** — 이미 활동에 참여자로 기록된 회원을 삭제하면 참조 무결성 문제 발생. 관리 복잡도 대비 필요성이 낮아 제외.
- **명부에 없는 외부 게스트 참여** — 회원만 참여자로 기록.
- **토너먼트 대진표 / 경기 결과 / 승패 추적** — 매칭은 1회 생성만 지원, 경기 결과는 추적하지 않음.
- **회원 실력 등급 자동 조정** — 초기 등급 고정.
