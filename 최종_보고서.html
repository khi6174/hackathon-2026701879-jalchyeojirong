📌 프로젝트 개요

팀번호: 2026701879 팀이름: 잘쳤지롱 (배드민턴 동아리) 팀원: 김용우 (1인 팀) 제출일: 2026-08-05

프로젝트 목표

동아리 임원이 활동 내역을 기록하고, 참여자를 명부에서 선택해 "누가 얼마나 참여했는지"를 추적하는 웹앱 개발

문제점 해결

  • 기존: 활동 기록이 채팅방에 흩어져 있어 언제 모였는지, 누가 얼마나 나왔는지 파악 어려움
  • 해결: 활동 기록을 중앙 집중식으로 관리하고, 회원별 참여 횟수를 자동으로 집계

    ---

    🎯 구현 기능

    ✅ 필수 기능

  • 회원 등록: 이름 + 실력 등급(상/중/하) 입력
  • 활동 등록: 활동명·날짜·장소·참여자·메모 입력 (각 항목 검증)
  • 활동 목록 조회: 최신순 정렬, 참여자 이름 표시
  • 활동 삭제: 확인 절차 포함
  • 활동 수정: 인라인 편집 방식

    ✅ 선택 기능

  • 검색: 활동명·장소 키워드로 실시간 필터링
  • 통계: 총 활동 수 / 총 참여 연인원 / 평균 참여 인원
  • 회원별 참여 횟수 랭킹: 참여가 많은 회원 상위 표시
  • 반응형 레이아웃: 모바일(768px 이하) / 데스크톱 자동 적응
  • 샘플 데이터: 시연용 6명 회원 + 5개 활동 자동 생성

    ✅ 추가 기능 - 매칭 시스템

실력 수준(상/중/하)을 고려한 공평한 팀 구성 매칭

#### 매칭 알고리즘

  • 실력 점수: 상(3점) + 중(2점) + 하(1점)
  • 최적화: 200회 반복 시뮬레이션으로 팀 점수 차이 최소화
  • 예시: (상3+하1=4점) vs (중2+중2=4점) → 완벽 균형 ✓

    #### 매칭 옵션

    • 1. 1vs1 매칭: 회원 2명 선택 → 바로 매칭 2. 2vs2 매칭: 회원 4명 선택 → 실력 균형 고려한 팀 구성 3. 3vs3 매칭: 회원 6명 선택 → 실력 균형 고려한 팀 구성

    #### 매칭 기능 개선 과정

  • 1차: 활동별 매칭 + 모달 선택 UI
  • 2차: 글로벌 회원 선택 매칭으로 통합
  • 최종: 매칭 유형 선택 모달 + 매칭 기록 자동 저장

    #### 데이터 공유 & 매칭 기록

  • 내보내기: 회원 + 활동 + 매칭 기록을 JSON 파일로 다운로드
  • 가져오기: JSON 파일을 업로드해서 데이터 복원 (자동 병합)
  • 용도: 팀원 간 데이터 공유, 백업/복원
